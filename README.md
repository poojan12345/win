# MINIORA Ecommerce

A lightweight, mobile-first storefront for MINIORA, a premium kids jewellery concept focused on gold and silver.

## Included
- Luxury editorial homepage
- Responsive storefront
- Product collection with filters
- Product search
- Wishlist interaction placeholder
- Persistent shopping cart using localStorage
- Quantity controls and totals
- Checkout form flow
- Empty-cart handling
- No framework or build step required

## Run
Open `index.html` in a browser, or serve the repository with any static web server.

## Before accepting live orders
This is a complete front-end storefront flow. Live commerce still needs real product data/photos, a secure backend/database, payment gateway integration, shipping/tax configuration, order management, policies, and production hosting.

Never put payment secret keys in `index.html`.
